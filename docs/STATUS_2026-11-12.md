A talk and write-up titled *Right in meaning, wrong in place?* in three parts:
1. **The live test (done).** Under a random-guess placebo and human labels, the LLM's guesses did not improve the map, our filter did not either, and frontier did as well.

If so, the answer to the author is: the semantics may be partly right, but ASP's score cannot turn them into better exploration.

- Run this from a fresh ssh login (`ssh -o ControlPath=none tyrone`), because older sessions lacked the docker group.

The queue moves each old run folder aside as `*_FAILED_ATTEMPT_HHMM` before it reruns that job.
