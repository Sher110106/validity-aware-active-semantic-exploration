The case

Eight reasons this is the right pick

Every claim below is verifiable against the linked paper, repository, or dataset.

01

Official code exists

The full pipeline ships in one repo: mapping stack, LLM completion, information-gain scoring, baselines, evaluation scripts. We reproduce, then improve. Two competing projects (ATLAS, aerial-ground mapping) have no public code.

02

Zero model training

No checkpoints to fit, no GPU queues, no convergence risk. The authors ran the whole system on an RTX 4060 laptop GPU. Our A6000 server is spare capacity, not a requirement.

03

Free data, no field work

Habitat simulator plus HM3D apartment scans, free for academic use. No robot, no drone, no permits, no campus logistics. The paper's own evaluation runs entirely in simulation.

04

Baselines to beat

Frontier exploration and semantic mutual-information exploration (SSMI, IEEE T-RO 2023) give objective targets: object-F1, graph-edit distance, room-finding time. Success is measurable, not vibes.

05

Built for three people

Three clean modules with explicit seams: scene-graph mapping stack, LLM prediction, viewpoint selection plus evaluation. Each person owns one; a weekly integration demo keeps the seams honest.

06

Midterm-ready

By week six or seven: one scene, the frontier baseline, a first informed policy, first numbers. The midterm presentation becomes a working demo instead of a promise.

07

Matches the curriculum

Exercises the "Perception for Action" half of the course: semantic mapping, active perception, LLM reasoning over scenes. The same skills the lectures teach, applied end to end.

08

The A6000 becomes leverage

Parallel scene runs, a local open-weights LLM instead of API dependence, and a LoRA fine-tune on scene-graph completion that targets a limitation the paper states itself. That last one is a genuine novel contribution.

Execution

The 12-week plan

About eight to ten person-hours per member per week, plus Friday labs. The midterm milestone lands at week six or seven.

Weeks 1-2

Environment

Dockerized ROS stack, Habitat, HM3D downloads, LLM API key. All three people on setup; this is the funnel.

Weeks 3-4

First loop

One full exploration loop end to end on one scene, repo as-is. Anything that fights back gets fixed now.

Weeks 5-7

Midterm

Frontier and random baselines, simplified information gain, first F1 and room-finding numbers. Demo ready.

Weeks 8-10

Improvements

Full two-stage LLM prompt, proper mutual information, second scene, node-type ablations, overnight runs.

Weeks 11-12

Delivery

Full evaluation, videos, report, code cleanup. Stretch goal: local LLM and LoRA fine-tune if ahead.

Division of labor

Three people, three modules

Mapping and simulation

Person A

ROS stack in Docker, Habitat, HM3D scenes, scene-graph export format. Owns the data path everyone else consumes.

LLM prediction

Person B

Two-stage prompts, ensemble sampling, hallucination filtering, consistency constraints. Owns the stretch goal: local LLM and fine-tuning.

Viewpoint selection and evaluation

Person C

Information-gain scoring, baseline policies, F1 and graph-edit metrics, figures and demo video. Owns the numbers.

Honest risks

What could go wrong, and the plan for each

R1ROS environment build

The mapping stack is C++ on ROS1 with old pinned dependencies. This is the classic multi-day sink.

Mitigation: Docker-first from week 1; ConceptGraphs, pure Python, is the one-week insurance plan.

R2LLM behavior

Hallucinated scene completions, API nondeterminism, rate limits. The paper itself needed manual rejection of bad outputs.

Mitigation: majority-consensus confidence filtering, plausibility checks, capped API budget, local model fallback on the A6000.

R3Experiment latency

LLM reasoning takes minutes per exploration step, so full scene runs span hours.

Mitigation: overnight batches, reduced ensemble size, several scenes in parallel on the A6000.

R4Dataset approval lag

HM3D requires a registration form, and approval takes time.

Mitigation: submit in week 1, before anything else. It is free for academic use.
