# Archived project records

These files are historical working records, not competing sources of final
results. They are retained because they document the proposal, scope changes,
audits, and operational decisions that led to the frozen evidence set.

Use the following files as the current source of truth:

- `../../FINAL_REPORT.md` for the final interpretation and limitations.
- `../RESULTS_INDEX.md` for the run and artifact map.
- `../REPRODUCE.md` for offline verification commands.
- `../../tyrone_mirror/DEVIATIONS.md` for the chronological engineering log.

The archived records fall into three groups:

- `IMPLEMENTATION_PLAN.md`, `IMPLEMENTATION_RESEARCH.md`, and `PLAN.md` are
  the proposal and implementation contract.
- `PAPER_ASSESSMENT_*.md`, `PHASE13_DIAGNOSTICS_*.md`, and `REVIEW_*.md` are
  dated analyses and independent audits that were superseded by the closeout.
- `ATTEMPTS.md`, `CONTROL.md`, `ENGINEERING_PILOT_REPORT_*.md`, `GOAL.md`,
  `MORNING_REPORT_*.md`, `NOTES.md`, `SESSION_REPORT_*.md`, `SPEC.md`,
  `SCIENTIFIC_CAMPAIGN_*.md`, and `GEMINI_PARTIAL_ANALYSIS_*.md` are
  operational notes and intermediate campaign reports.
- `proposal_explainer/` is the original course-proposal web brief; it is
  retained as historical context and is not the results presentation.

Nothing in this directory authorizes a new paid run. The campaign is frozen.
