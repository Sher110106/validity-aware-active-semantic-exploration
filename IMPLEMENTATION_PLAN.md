## 12. Phase 8: proposed extensions

Use a separate working branch or sibling checkout.

### 12.1 Whole-graph validator

Run after every sampled completion. It uses only the partial observed graph and fixed geometric rules; reference ground truth is permitted only for post-hoc labels.

Check:

1. Exactly one parseable YAML block.
2. Allowed node and edge schema.
3. Finite dimensions and poses.
4. Unique identifiers.
5. Valid edge endpoints.
6. Preservation of observed nodes.
7. Object-to-room parent relations.
8. Room containment.
9. Observed-to-predicted and predicted-to-predicted AABB conflicts.
10. Crossings of impassable structures without a door.

Remove invalid predicted nodes with a reason. Reject a completion that cannot preserve the observed graph. If all completions fail, use the observed graph plus a geometric frontier fallback and continue exploring.

### 12.2 Held-out calibration

For each matched hypothesis, calculate raw support as the fraction of eight completions containing it. Match by semantic label, parent room, and fixed spatial thresholds.

Use leave-one-scene-out calibration:

- Fit the monotone support-to-probability map on three scenes.
- Evaluate on the fourth.
- Rotate the held-out scene.
- Tune the acceptance threshold and beta only on calibration scenes.

The calibration label is whether the hypothesis matches the fully explored reference under evaluator thresholds. It must not influence online validation decisions.

### 12.3 Risk-sensitive score

Implement:

~~~~text
U(x) = I_object(x) + lambda_room I_room(x) - lambda_distance d(x) - beta R(x)
~~~~

R(x) is the mean of 1 - calibrated support over predicted nodes visible from x, and is zero when none are visible.

Evaluate:

~~~~text
filter-only
calibration-only (beta = 0)
combined calibrated-risk
~~~~

Do not mix calibration data with held-out scene seeds.

checkpoints 0, 25, 50, 75, 100, 120 m
~~~~

Primary outcomes:

- Path-normalized AUC for object precision, recall, and F1.
- Reference-size-normalized GED AUC.

Diagnostics:

- Completion validity.
- Survivor recall and diversity.
- Brier score and expected calibration error.
- Reliability plots.
- Evaluator-matched unseen-room discovery.
- False-positive detours and collisions.
- Cached-replay time and live-LLM time.
- Query count and API cost.

Report per-scene values and paired scene-seed differences with scene-cluster bootstrap 95% confidence intervals.

The combined method is useful only if it reduces invalid hypotheses and false-positive detours without more than 0.05 loss in object-F1 AUC or 10% increase in normalized-GED AUC relative to official ASP. If a guardrail fails, report the trade-off without claiming improvement.
